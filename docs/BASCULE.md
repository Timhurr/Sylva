# Basculer Sylva sur un compte Claude personnel

À utiliser le jour où l'accès au compte Claude actuel n'est plus possible. Tout ce qu'il faut est déjà hors de ce compte : le code, les images, les tests, l'atelier d'images et la passation sont dans ce dépôt GitHub personnel.

## Le jour J (environ 15 minutes)

1. **Créer un compte Claude personnel** avec une adresse e-mail privée (abonnement payant recommandé pour utiliser Claude Code).
2. **Connecter GitHub** : dans Claude Code (web ou application de bureau), relier le compte GitHub `Timhurr` et choisir le dépôt `Timhurr/Sylva`.
3. **Donner le contexte privé** : joindre au premier message le fichier `Sylva_CLAUDE_complet_PRIVE.md`. Il est gardé hors de GitHub public : sur l'ordinateur ou le cloud personnel, ou dans le dépôt privé `Timhurr/Sylva-prive` s'il a été créé.
4. **Envoyer ce message de démarrage :**

   > Tu reprends le projet Sylva. Lis CLAUDE.md en entier, puis la section « Journal de développement », et le fichier privé joint. Lance node tools/tests/fulltest.js pour vérifier que tout passe. Dis-moi ensuite en trois lignes où on en est et ce que tu proposes en premier.

5. **Vérifier une publication** : demander un petit changement, par exemple le numéro de version, et contrôler qu'il apparaît sur https://timhurr.github.io/Sylva/ (Réglages, en bas).

## Ce qui ne bascule pas (à refaire si besoin)

- L'historique des conversations et la mémoire du compte actuel : remplacés par `CLAUDE.md`, son journal de développement et le fichier privé.
- L'atelier d'images en ligne (artefact claude.ai) : la copie `docs/atelier-images.html` fait foi. On peut la republier depuis le nouveau compte.
- Les maquettes Design : elles ne sont pas indispensables, l'appli en ligne est la référence.

## Rien à refaire

- Le site, le dépôt, les images, les tests.
- Les clés Pl@ntNet et MapTiler : elles sont dans tes comptes personnels et dans les Réglages de Sylva sur l'iPhone.
- Les données de l'appli (spots, sac, bivouacs, journal) : elles sont sur le téléphone, pas dans Claude.
