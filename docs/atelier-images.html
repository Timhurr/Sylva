Atelier d'images

Chaque image a un prompt prêt à copier pour ChatGPT et un nom de fichier. Coche une image quand elle est faite : tes coches restent dans ce navigateur.

  1. Ta référenceGarde ta meilleure image PLS : c'est ton « image de style » pour toutes les autres.
  2. Joins-laDans ChatGPT, joins l'image de style, puis colle le prompt copié ici.
  3. VérifieContrôle le geste. Si un détail est faux, demande la correction précise.
  4. RenommeTélécharge l'image et donne-lui le nom indiqué, par exemple ps_pls.png.
  5. EnvoieEnvoie-moi les images par lots de 10 dans la conversation : je les intègre à l'appli.
